# 개인정보처리방침 — 초키보드(Chalkieboard)

English: [Privacy Policy](/legal/privacy/?lang=en)

**시행일: 2026년 10월 12일**

초키보드는 교사와 발표자가 수업 자료와 판서를 다루는 아이패드 도구입니다. 학생
계정을 만들거나 학생의 신원을 등록하도록 요구하지 않습니다. 다만 자료·판서·음성
명령에는 개인정보가 들어 있을 수 있습니다. 이 방침은 기기 안 처리와 아래의 선택형
외부 전송을 설명합니다.

---

## 1. 요약

**초키보드는 수업 자료 파일·판서 화면 그림·시간표를 개발자 서버로 보내지 않습니다.**
기기 안과, 사용자가 선택한 경우 사용자 본인의 iCloud에 보관하며 개발자는 접근할 수 없습니다.

**'Decisions 사용' 설정이 있는 버전에서 Decisions는 기본으로 꺼져 있습니다.**
음성 명령은 Apple의 기기 안 인식과 지원 명령의 기기 안 규칙을 씁니다. 새 전송 동의와
별도로 입력한 OpenAI 음성 키가 있어야 선택한 명령 글·화면 맥락을 OpenAI로 보낼 수
있습니다(5.2항). 기존 TypeSafe 키와 동의는 사용하지 않습니다.

빌드 `202610061343`에는 이전 음성 판단 서비스가 없습니다. TypeSafe를 사용할 수 있는 그 이전 TestFlight
빌드는 선택과 처리 방식이 다르며, 선택형 학생 말 맥락도 보낼 수 있습니다(5.3항).
방침을 고쳤다고 이미 설치된 이전 빌드의 동작이 바뀌는 것은 아닙니다.

학생 신원을 등록하도록 요구하지 않습니다. 사용자의 자료나 음성 명령에 들어 있는
개인정보의 처리 범위는 5·7항에 설명합니다.
iCloud나 App Store에서 쓰는 Apple 계정, 사용자가 연 웹사이트의 로그인은 초키보드
계정과 별개입니다. 웹사이트는 각자의 방침에 따라 자기 서비스를 처리합니다.

## 3. 기기 권한

- **사진** — 사용자가 직접 고른 사진을 판서 면에 붙일 때만 씁니다. 앨범 전체를
  훑거나 사진을 외부로 보내지 않습니다.
- **iCloud Drive** — 사용자가 맥·윈도우에서 준비한 수업 자료를 아이패드에서
  열기 위한 통로입니다. 파일은 **사용자 본인의 iCloud 계정**에 있고, 개발자
  서버를 거치지 않습니다.
- **외부 디스플레이(에어플레이·HDMI)** — 연결되면 판서 화면을 송출합니다.
  송출은 화면 그림만 보내며 어떤 데이터도 저장하지 않습니다.
- **마이크·음성 인식** — 설정에서 음성 명령(프로)을 켠 경우에만 씁니다. 소리는
  **이 아이패드 안에서** 글자로 바뀌며(기기 안 받아쓰기), 녹음하거나 저장하지 않고
  소리를 기기 밖으로 보내지 않습니다. 별도 선택인 **교사 목소리 확인**은 기본으로 꺼져 있습니다.
  이 확인을 켤 때만 목소리 등록이 필요하며, 특징값(숫자 목록)은 기기의 키체인에만 저장합니다.
  확인을 끄면 목소리 신원 확인 없이 들은 말에서 명령을 판단하며, 마이크 버튼으로 듣기를 멈출 수 있습니다. 자주 쓰는 명령을
  빠르게 알아듣기 위해 말의 지문(되돌릴 수 없는 해시값)과 명령 이름을 기기 안에
  기억할 수 있습니다.
- **시스템 조작과 Siri** — App Intents를 통해 음성 명령 켜기·끄기, 수업 열기, 다음 쪽·
  이전 쪽, 펜·지우개 조작을 Siri와 단축어에 제공합니다. Siri로 부르면 사용자의 Siri
  설정과 Apple 방침에 따라 말을 처리하며, 앱은 실행할 조작을 받습니다. 앱이 마이크로
  듣는 음성 명령과는 별도 입구이며 Decisions를 쓰지 않습니다(5.1항).
- **교실 장면 추정** — 음성 명령이 켜진 수업 중에는 교실 소리를 **이 아이패드 안에서만**
  살펴 지금이 설명·모둠 활동·발표 같은 어느 장면인지 짐작합니다. 쓰는 것은 목소리가
  몇 개인지, 소리 크기, 선생님 목소리인지의 점수 같은 숫자뿐입니다. 소리는 기기 밖으로
  보내지 않습니다. 이 짐작은 음성 명령을 더 조심해서 실행하는 데만 씁니다.
  장면 짐작(장면 이름과 확률)은 기기 밖으로 보내지 않습니다. Decisions를 켜면 별도의 교실
  사실인 소리 출처·크기·토막 시각 등이 명령 요청에 실릴 수 있습니다(5.2항). 이 사실에는
  소리나 전사문이 들어 있지 않습니다. 별도의 기본 꺼짐 선택을 켜면 최근 발화와
  화자별 맥락도 OpenAI로 보낼 수 있습니다(5.2항). 이전 빌드는 5.3항에 설명합니다.

## 4. 광고

무료로 쓰는 동안 **수업 시간을 충전하기 위해 사용자가 직접 선택해서 보는 보상형
광고**만 있습니다. 광고 한 편을 보면 수업 시간 1시간이 충전됩니다. 앱이 스스로
띄우는 배너나 전면 광고는 없고, 수업 중이나 송출 화면에는 광고가 나오지 않습니다.
광고는 Google AdMob이 제공합니다.

- 초키보드는 **개인화되지 않은 광고만** 요청합니다. 광고 식별자(IDFA)를 쓰지
  않으며, iOS의 앱 추적 투명성(ATT) 권한을 요청하지 않습니다.
- 그래도 AdMob은 광고를 보여 주고 부정 클릭을 막기 위해 IP 주소, 기기 종류 같은
  기본 기술 정보를 처리합니다. 처리 내용: https://policies.google.com/technologies/partner-sites
- 유럽 이용자에게는 광고를 띄우기 전에 동의 창(Google UMP)이 먼저 뜰 수 있습니다.
- **초키보드 프로를 구독하면 수업 시간이 무제한이 되어 광고를 볼 필요가 없습니다.**

초키보드는 광고 목적으로 사용자 데이터를 AdMob에 따로 넘기지 않습니다.

## 5. 음성 명령·선택형 Decisions·시스템 조작

### 5.1. Apple 음성 인식과 이 아이패드 안의 명령

앱은 마이크 소리를 Apple의 기기 안 음성 API로 받아쓰고, 지원하는 명령은 이 아이패드
안의 규칙으로 판단합니다. “시리야”라고 말하거나 Siri를 켤 필요가 없습니다. '호출어로만
듣기'를 끄면 앱의 호출어도 필요하지 않습니다. 음성 명령에는 프로와 3항의 마이크·음성
인식 권한이 필요합니다. 지원 언어는 기기·OS·Apple의 언어 자료에 따라 다르며, 자료를
내려받을 때 인터넷이 필요할 수 있습니다. 기기 안 인식이 불가능하면 몰래 서버 음성
인식으로 바꾸지 않습니다.

Decisions가 꺼져 있어도 지원하는 쪽·도구 명령, 지원하는 한국어 정중 표현, 하나로 일치하는
자료 이름, 명시적인 영어·한국어 받아 적기와 정답 공개 명령, 하나로 일치하는 화면의
앱 단추 이름은 기기 안에서 처리합니다. 정해진 지원 범위이며 모든 문장을 알아듣는다는
뜻은 아닙니다. 선택한 글에 강조 표시하기와 더 자유로운 요청은 사용자가 Decisions를 켠 경우
Decisions의 판단을 쓸 수 있습니다.

별도의 App Intents 조작은 음성 명령 켜기·끄기, 수업 열기, 다음 쪽·이전 쪽, 펜·지우개
선택입니다. 단축어와 시스템 조작 수단에서 실행할 수 있습니다. 아이패드 손쉬운 사용의
Apple 보컬 단축어에 원하는 말을 등록하면 “시리야” 없이도 부를 수 있지만, 사용자가
따로 설정하는 시스템 기능입니다. Siri로 부르면 Apple이 사용자의 Siri 설정과 방침에
따라 요청을 처리합니다. 초키보드는 실행할 조작을 받으며 Siri 소리를 녹음하거나 이
조작에 Decisions를 쓰지 않습니다.

### 5.2. 선택형 OpenAI Decisions

Decisions는 기본으로 꺼져 있습니다. 이번 업데이트는 기존 TypeSafe 키·이전 음성 판단 사용
설정·그 동의를 물려받지 않습니다. 켜려면 새 전송 고지에 동의해야 하며, 실제 전송에는
별도로 입력한 OpenAI 음성 API 키도 필요합니다. 키를 저장해도 켜지거나 연결 확인 요청을 보내지 않습니다.
인터넷 연결과 OpenAI API 결제가 필요하며 비용은 초키보드 프로와 별도입니다.

Decisions를 켜면 앱의 거름을 지난 명령 후보에 다음이 포함될 수 있습니다.

- **명령 전사문과 대안 전사문** — 호출어 뒤의 말, 음성 동작 후 8초 안의 이어 말,
  또는 호출어 없이 들린 말 가운데 자료·도구·단추·기능·쪽 번호·시간과 맞는 말입니다.
  사람 이름이 포함될 수 있습니다. 교사 목소리 확인은 선택 사항이며 완벽하지 않으므로
  명령 후보에 교사의 말만 들어간다고 보장하지 않습니다.
- **선택한 화면 맥락** — 자료·도구·단추 이름, 현재 자료·쪽·도구, 말과 겹치는 쪽의 글과
  표시, 관찰한 글의 출처·위치·겹친 구간, 최근 음성 동작과 보이는 앱 단추 상태입니다.
  글에 개인정보가 들어갈 수 있지만 문서 전체·사진·판서 화면 녹화는 보내지 않습니다.
- **교실 소리 사실** — 앱이 만든 소리 출처·크기·토막 시각과 알려진 활동 사실입니다.
  소리나 전사문은 들어 있지 않습니다.
- **별도로 선택한 웹 맥락** — '웹 화면 음성 조작'은 기본으로 꺼져 있습니다. 두 선택을
  모두 켜면 현재 웹 제목, 제공된 단추·입력칸의 이름과 종류, 허용 동작과 말에 겹치는
  화면 글을 보낼 수 있으며 사람 이름도 포함될 수 있습니다. 웹사이트를 여는 것만으로
  켜지지 않습니다. 웹사이트 자체는 각자의 방침을 따릅니다.

**명령 낱말 밖의 말도 맥락으로 해석**은 기본으로 꺼진 별도 선택입니다.
Decisions를 켜고 이 선택에 명시적으로 동의하면 알려진 명령 낱말이나 최근 음성 동작이
없어도 수업에서 들은 말의 후보와 말하는 도중의 전사문을 OpenAI로 보낼 수 있습니다.
평소 학생의 말과 이름도 포함될 수 있으며 같은 API 비용과 OpenAI 보관 조건이 적용됩니다.
모든 사람의 말을 공유할 권한이 있을 때만 켜세요. 호출어로만 듣기는 계속 적용됩니다.
최근 발화 이력과 웹 맥락은 켜지지 않으며 각각 별도로 선택해야 합니다. 끄면 진행 중인
요청을 취소하고 늦은 응답을 버리지만 OpenAI가 이미 받은 정보를 되가져오지는 못합니다.
Decisions를 끄면 이 선택의 동의도 해제됩니다.

소리 원본·목소리 특징값·유사도 점수는 OpenAI에 보내지 않습니다. 기존 설정값이 남아
있어도 최근 학생 말 전사문·목소리별 전사문·누적 교실 그림은 기본적으로 제외됩니다.
별도로 **교실 발화 맥락 사용**에 명시적으로 동의할 때만 포함하며, 이 선택은 따로 끌 수
있습니다. 최근 20초의 학생·다른 사람 전사는 최대 두 건(각 160자, 합계 320자), 최근
30초의 앞선 화자별 발화는 최대 여섯 건(각 160자, 합계 480자)이며 세션 안에서만 쓰는
목소리 번호와 상대 시각이 포함됩니다. 현재 발화는 전사문을 중복하지 않고 목소리 번호와
시각을 더할 수 있습니다. 이전 활동·발언권 추정과 경과 시각, 현재 세션의 교사 목소리
번호도 포함될 수 있습니다. 화자별 발화에는 사용 가능한 화자 분석이 필요합니다.
전사문에 이름 등 개인정보가 들어갈 수 있습니다. 최근 맥락은 수업 중 iPad의 메모리에
있으며 설정을 바꾸거나 수업을 닫으면 지워집니다. 끄면 진행 중인 기기 요청을 취소하고
늦은 응답을 버리지만 OpenAI가 이미 받은 정보를 되가져오지는 못합니다. 이 선택을 켜지
않아도 명령 후보나 선택한 화면 글에 학생의 말이나 이름이 포함될 수 있습니다. 이 선택은
음성 판단 기록 작성을 켜거나 기존 기록을 지우지 않습니다.

기기 안 세션 준비는 HTTP 요청을 보내지 않습니다. **연결 확인(유료 요청)**은 정해진
합성 명령 한 번을 OpenAI로 보냅니다. Decisions를 끄면 진행 중인 기기 요청을 취소하고
늦은 결과를 버리며 키·자료·기존 기록은 보존합니다. 취소해도 이미 받은 데이터를
되가져오거나 비용이 없다고 보장할 수 없습니다. 마이크 명령도 멈추려면 음성 제어를 끄세요.

전송처는 OpenAI API입니다. OpenAI는 요청 글·맥락, 인증용 API 키와 필요한 네트워크
정보를 받습니다. [API 데이터 안내](https://developers.openai.com/api/docs/guides/your-data)에
따르면 API 데이터는 기본적으로 모델 학습에 쓰지 않습니다. 기본 부정 사용 감시 기록은
일부 예외를 제외하고 고객 내용을 최대 30일 보관할 수 있습니다. 프롬프트 캐시는 암호화된
키·값 텐서를 최대 24시간 보관할 수 있습니다. 데이터 무보관은 자격과 승인이 필요하므로 개인 키에
자동 적용된다고 가정하지 않습니다. Decisions를 끄는 것은 서버 삭제 요청이 아닙니다.
계정별 처리·보관 선택은 사용자의 OpenAI 계약에 따릅니다.

### 5.3. 이미 설치된 이전 TestFlight 빌드

빌드 `202610061343`에는 TypeSafe가 없으므로 키 입력이나 전송 선택이 없고, 이전에
저장한 키도 TypeSafe 연결에 쓰지 않습니다. 기존 키와 기록은 남겨 둡니다. 이전의
이전 음성 판단 사용 토글이 있는 버전은 그 버전의 동의 후 TypeSafe를 씁니다. 두 경우 모두
5.2항의 OpenAI Decisions 버전과 다릅니다.

독립적인 이전 음성 판단 사용 동의 선택도 없던 더 이전 TypeSafe TestFlight 빌드는 음성 명령이 켜져 있고 키가 있으면
위에서 설명한 명령 후보·화면·웹·교실 맥락을 보낼 수 있습니다. 새로 마련한 독립적인
이전 음성 판단 사용 동의 선택은 없습니다. 이 방침을 고쳐도 설치된 이전 빌드의 동작은 꺼지지
않습니다. 그 빌드의 전송을 원하지 않으면 키를 넣지 않거나 해당 빌드의 설정에서 키를
지우거나 음성 명령을 끄세요.

그 이전 빌드에는 별도로 켤 수 있는 다음의 전사문 맥락 기능도 있습니다.

- **최근 학생 말 맥락(선택)** — 학생 말 전사문이 TypeSafe(미국)로 전송된다.
  '학생 말 맥락'을 켜면 기존 음성 명령 요청에 최근 20초의 전사문 최대 두 개(각 160자 이내)가
  함께 실릴 수 있습니다. 교사가 아닌 다른 목소리라는 근거가 있으나 학생인지 확인되지 않은 말은
  `other`로 표시하고, 화자를 알 수 없는 말은 보내지 않습니다. 이 설정은 기본으로 꺼져 있으며
  맥락만을 위한 추가 요청은 하지 않습니다. 이 선택은 교사 음성 확인을 대신하거나 명령 실행 권한을 주지 않습니다.
- **목소리별 말 조각과 교실 그림(연속 화자 분석을 켠 수업, 선택)** — 선생님·학생·다른 사람의 말 전사문이
  TypeSafe(미국)로 전송된다. 연속 화자 분석을 켜면 기존 음성 명령 요청에 최근 30초 동안 들린 말을 목소리별로
  나눈 전사문(최대 6개, 각 160자·모두 480자 이내)과 앱이 그 목소리에 붙인 번호(v1…)·몇 초 전인지가 함께
  실립니다. TypeSafe는 조각마다 누가 말했는지와 지금 교실 활동·누가 말하는 중인지를 판단하고, 앱은 그 판단
  (활동 이름, 누가 말하는 중인지, 선생님 목소리 번호)을 수업 동안 이 아이패드 메모리에만 들고 있다가 다음
  요청에 함께 보냅니다. 소리와 목소리 특징값은 보내지 않으며 수업 화면을 닫으면 버립니다. 이 판단은 호출어
  없이 들린 말을 명령으로 받을지 더 조심스럽게 정하는 데만 쓰고, 호출어로 부른 명령은 막지 않습니다.
  이 설정은 기본으로 꺼져 있고 이 조각만을 위한 추가 요청은 하지 않습니다.


이전의 추가 맥락 기능은 교사 확인을 대신하거나 명령 실행 권한을 주지 않습니다.
소리 원본과 목소리 특징값은 기기 안에 남습니다. 현재 버전을 설치해도 이 전사문 전송이나
이전의 판단 기록 작성이 다시 켜지지 않습니다.

## 7. 아동의 개인정보

초키보드는 교사가 쓰는 도구이며 학생 계정 서비스가 아닙니다. 교사는 자료나 판서에
학생 이름·사진 등 개인정보를 넣을 수 있습니다. 해당 파일은 기기와, 선택한 경우 그
교사의 iCloud에 남으며 개발자는 접근할 수 없습니다.

Decisions를 끄면 명령 전사문이나 화면 맥락을 OpenAI로 보내지 않습니다. Decisions를 켜면 별도
교실 발화 맥락을 켜지 않아도 명령 후보·자료와 단추 이름·말과 겹치는 쪽의 글에 들어
있는 학생 이름이나 말이 OpenAI로 전송될 수 있습니다(5.2항). 웹 맥락은 별도로
켜야 하며 학생 소리 원본은 보내지 않습니다. 별도로 선택하면 5.2항의 최근 학생 말과
목소리별 전사문도 보낼 수 있습니다. 이전 빌드의 처리는 5.3항에 설명합니다.

학교·교육청의 방침과 아동의 개인정보에 적용되는 조건을 확인하고, 외부 제공 권한이
있는 정보에만 Decisions를 사용해 주세요. 교사의 Decisions 사용 동의만으로 다른 사람의 개인정보를
보낼 권한이 자동으로 생기는 것은 아닙니다.

## 8. 보관과 삭제

- 앱을 삭제하면 기기 안의 판서·자료·설정이 함께 지워집니다.
- **OpenAI 음성 키와 기존 TypeSafe 키** — OpenAI 음성 키는 별도 키체인 자리에 둡니다.
  설정 ▸ 음성 제어에서 이 OpenAI 키를 지우면 Decisions도 꺼지고 진행 중인 요청이
  취소됩니다. Decisions를 끄는 것만으로 키를 지우지는 않습니다. 기존 TypeSafe 키는
  읽거나 복사·사용·삭제하지 않고 보존하며, 새 키 삭제 선택으로 기존 키가 지워지지
  않습니다. 저장된 키만으로 전송에 동의한 것으로 처리하지 않습니다.
- **이전 TypeSafe 빌드의 음성 판단 기록** — 해당 이전 빌드의 새 기록에는 ID·단계·종류·모델 이름·시간·결과 코드·건수와
  분석 구간·확인 설정 같은 진단용 숫자 및 고정 상태 메타데이터를 남길 수 있습니다.
  받아쓴 말 원문, 요청·답변 본문, 음성, 목소리 특징값은 새 기록에 남기지 않습니다. 다만 교사 목소리를 등록해
  쓰면, 명령 차례마다 등록된 목소리와 비교한 유사도 점수(숫자)가 새 기록에도 함께 남습니다. 이전 형식의 기록에는
  말 원문과 판단 결과가 남아 있을 수 있습니다. 설정 ▸ 음성 제어 ▸ 저장된 판단 기록 삭제에서 지울 수 있습니다. 기록은 이 기기에 두고 사용자 본인의 iCloud Drive
  `초키보드` 폴더 안 `판단기록` 폴더에 사본을 둡니다(개발자에게 가지 않습니다).
  테스트 빌드(TestFlight)에서는 기본으로 켜져 있고 App Store 판에서는 꺼져 있습니다.
  30일이 지나거나 50MB를 넘으면 오래된 것부터 지우고(사본도 함께), 설정 ▸ 음성 제어에서 끄거나
  지울 수 있습니다. 지우면 그 기기의 사본도 지웁니다. 기기 백업에는 넣지 않습니다.
  현재 출시판은 이전 음성 판단 서비스 판단 기록을 새로 만들지 않습니다. Decisions가 꺼져 있어도
  기존 기록의 보관 기간 정리와 삭제 선택은 제공됩니다. 이 iPad 소유로 확인된 기록과
  사본만 지우며, 출처 불명 파일과 다른 기기의 사본은 남깁니다. 같은 계정의 iCloud에
  연결되면 확인된 사본의 삭제를 재개합니다. 정리를 위해 이전 기록을 새로 업로드하지 않습니다.
- **수업 흐름**('수업 흐름 남기기'를 켰을 때) — 장면 이름과 바뀐 시각만 7일 동안 남깁니다.
- iCloud Drive의 `초키보드` 폴더는 사용자의 파일이므로 남습니다. 원하시면
  파일 앱이나 파인더에서 직접 지우시면 됩니다.
- 개발자가 보관하는 사용자 데이터는 **없습니다.** 따라서 열람·정정·삭제를
  개발자에게 요청하실 일도 없습니다.
